# Implementación de agilidad en Khanauky

## Propuesta de trabajo ágil

Para el proyecto Khanauky se propone aplicar Scrum como marco principal de organización y Kanban como apoyo para visualizar el avance de las actividades.

Scrum permitirá organizar el trabajo en periodos cortos llamados Sprint. En cada Sprint se seleccionarán funcionalidades prioritarias del sistema y se trabajará hasta completar una entrega revisable.

Kanban permitirá visualizar el estado de cada actividad mediante un tablero, facilitando identificar qué tareas están pendientes, en proceso, en revisión o terminadas.

## Elementos que se implementarán

### Product Backlog

Se utilizará un Product Backlog para organizar las funcionalidades principales del sistema Khanauky.

Entre los elementos iniciales se consideran:

- Registrar clientes.
- Registrar pedidos.
- Atender pedidos.
- Consultar y actualizar stock.
- Registrar información de producción.
- Registrar salidas de almacén.
- Consultar estado de pedidos.
- Generar alertas de stock mínimo.

### Sprint

El trabajo se organizará en Sprint de una semana. Cada Sprint tendrá un objetivo específico y seleccionará las actividades prioritarias del Product Backlog.

Para el Sprint propuesto se establece:

**Duración:** 1 semana.

**Objetivo del Sprint:** completar y validar las funcionalidades relacionadas con la atención de pedidos y el control de stock.

Actividades seleccionadas:

- Registrar pedido.
- Atender pedido.
- Consultar y actualizar stock.
- Validar stock mínimo.
- Generar alerta para Almacén.

Al finalizar el Sprint se deberá contar con una entrega verificable de estas funcionalidades.

### Revisión

Al finalizar cada Sprint se revisarán las funcionalidades desarrolladas para comprobar que cumplen con los requisitos definidos.

Si se detectan observaciones, estas podrán incorporarse como nuevas tareas o ajustes dentro del siguiente ciclo de trabajo.

## Roles propuestos

Para adaptar Scrum al proyecto Khanauky se consideran los siguientes roles:

- Product Owner: representa las necesidades de la empresa y prioriza las funcionalidades.
- Scrum Master: facilita la organización del trabajo y ayuda a resolver impedimentos.
- Equipo de desarrollo: implementa, documenta y valida las funcionalidades del sistema.

En este proyecto académico, un mismo integrante puede asumir más de una responsabilidad debido al tamaño reducido del equipo.

## Conclusión

La implementación de Scrum y Kanban permitiría organizar mejor el desarrollo de Khanauky, priorizar las funcionalidades más importantes, visualizar el avance del trabajo y responder con mayor facilidad a cambios en los requisitos.
