# Validación del proyecto Khanauky con un enfoque ágil

## ¿Es válido aplicar agilidad al proyecto Khanauky?

Sí. El proyecto Khanauky puede desarrollarse aplicando un enfoque ágil porque sus funcionalidades pueden organizarse en entregas pequeñas y progresivas.

El sistema incluye procesos como el registro de clientes, registro de pedidos, atención de pedidos, control de stock, gestión de producción y consulta del estado de los pedidos. Estas funcionalidades pueden trabajarse de forma independiente y revisarse conforme avance el proyecto.

Además, durante el desarrollo pueden aparecer cambios en los requisitos, como nuevas validaciones de stock, ajustes en el proceso de atención de pedidos o modificaciones en la gestión de almacén. Un enfoque ágil permite incorporar estos cambios sin tener que rehacer todo el proyecto.

## Ventajas para Khanauky

- Permite desarrollar las funcionalidades por etapas.
- Facilita revisar avances de manera frecuente.
- Permite incorporar cambios de requisitos de forma controlada.
- Mejora la comunicación entre los integrantes del equipo.
- Facilita detectar errores antes de llegar a una versión final.
- Permite priorizar las funcionalidades más importantes para la empresa.

## Conclusión

El proyecto Khanauky es adecuado para trabajar con agilidad porque puede dividirse en funcionalidades pequeñas, permite realizar entregas progresivas y puede adaptarse a cambios durante el desarrollo sin afectar completamente el proyecto.
